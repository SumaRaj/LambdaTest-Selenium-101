# LambdaTest Selenium 101 Certification (Java)

## Overview
This repository contains the Java Selenium Automation script for the LambdaTest Certification.

## Prerequisites
- Java 8+
- Maven

## Configuration
1. Open `src/test/java/com/lambdatest/CertificationTest.java`.
2. Update `username` and `accessKey` with your LambdaTest credentials.

## Execution
To run the tests in parallel on LambdaTest Cloud Grid:
`mvn test`

## Environment
Tests run in parallel on:
1. Windows 10 Chrome
2. macOS Catalina Safari
